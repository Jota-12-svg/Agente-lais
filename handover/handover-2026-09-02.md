  do dono (4 msg, billing 0,88→0,95) → fator ×0,92: **a correção pro preço cheio está certa**,
  a estimativa fica dentro de ~8% do billing.

  tokens. Em produção o system prompt é cacheado (10× mais barato, research §5) → conversa de
  4 turnos cai de ~R$ 0,07 pra ~R$ 0,03. `/custos` mostra esse breakdown.
- **`prototipo-tom-014/CUSTOS.md`** — nota de referência pro desenho do runtime (névoa "Stack
  e hospedagem" do mapa): salvar contexto no Supabase **não** baixa custo de API (modelo é sem
  estado); os levers reais são cache de prefixo (≥4.096 tokens — o prompt cruza isso quando o
  catálogo dos tickets 011/032 entrar), debounce de mensagens, resumo em vez de histórico cru,
  `flash-lite`, Batch pro laço de aprendizado. Estimativa somando tudo: ~R$ 4–15/mês.
